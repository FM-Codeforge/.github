# F.M. Codeforge Global Configurations

This repository acts as the central control plane for the **F.M. Codeforge** GitHub organization. It contains organization-wide defaults and community health files.

### 📁 Directory Structure

* `/profile/README.md`: The public-facing profile rendered on the organization's home page.
* `/.github/ISSUE_TEMPLATE/`: Global issue templates for bug reports and feature requests.
* `/.github/PULL_REQUEST_TEMPLATE.md`: The standard PR template used across all FM Codeforge repositories.

*Note: Changes made to workflows or templates in this repository will cascade and apply globally to all repositories within the organization unless overridden locally.*
